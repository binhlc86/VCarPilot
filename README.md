# VCarPilot - Trợ lý giọng nói tiếng Việt cho Android Box ô tô

Kênh phát hành chính thức (Releases & OTA Updates) cho ứng dụng **VCarPilot**.

## Tải về & Cài đặt trên Android Box
- **Bản mới nhất (v1.0.0):** [Tải trực tiếp VCarPilot-1.0.0.apk](https://github.com/binhlc86/VCarPilot/releases/download/v1.0.0/VCarPilot-1.0.0.apk)
- **Tất cả các bản phát hành:** Xem tại [Releases](https://github.com/binhlc86/VCarPilot/releases)

## Cập nhật qua mạng (OTA)
Ứng dụng tự động kiểm tra phiên bản mới từ file [version.json](https://raw.githubusercontent.com/binhlc86/VCarPilot/main/version.json). Khi có bản mới, ứng dụng sẽ hiện thông báo cập nhật một chạm.
